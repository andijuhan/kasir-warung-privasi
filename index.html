Kebijakan Privasi — Kasir Warung

Terakhir diperbarui: 16 November 2026

Aplikasi Kasir Warung adalah aplikasi kasir untuk toko kelontong dan warung kecil. Kebijakan ini menjelaskan data apa yang diproses Aplikasi dan bagaimana data itu dijaga.

Ringkasan singkat

  • Data toko disimpan di perangkat Anda sendiri. Aplikasi tidak memiliki server dan tidak mengunggah data barang, transaksi, pelanggan, atau hutang.
  • Tidak ada akun online. Akun admin dibuat di perangkat dan hanya berlaku di perangkat itu.
  • Satu-satunya koneksi internet adalah untuk pembelian versi Pro melalui Google Play (jika Anda membelinya).

Data yang disimpan di perangkat

Aplikasi menyimpan data berikut hanya di penyimpanan internal perangkat:

  • Nama toko dan nama admin (yang Anda isi sendiri)
  • Data barang: nama, harga, modal, stok, barcode/SKU, kategori
  • Data transaksi penjualan, pembelian, dan retur
  • Data pelanggan dan hutang/piutang
  • Pengaturan aplikasi (suara, printer, pembulatan)

Data ini tidak dikirim ke kami maupun ke pihak ketiga. Data akan hilang bila aplikasi dihapus atau data aplikasi dibersihkan, kecuali Anda membuat cadangan (ekspor) sendiri.

Aplikasi tidak meminta akses kamera, kontak, lokasi, mikrofon, atau penyimpanan umum.

Pembelian dalam aplikasi (Google Play)

  • Pembayaran diproses sepenuhnya oleh Google Play. Kami tidak menerima dan tidak menyimpan data kartu atau rekening Anda.
  • Untuk memverifikasi pembelian, aplikasi mengirim token pembelian dari Google Play ke layanan verifikasi kami. Layanan itu menyimpan: hash token pembelian, hash identitas perangkat (untuk mencegah satu pembelian dipakai di banyak perangkat), ID pesanan, dan tanggal verifikasi.
  • Data toko Anda tidak pernah ikut dikirim.

Data yang tidak kami kumpulkan

Kami tidak mengumpulkan: nama, email, atau nomor telepon pengguna; lokasi perangkat; kontak, foto, atau berkas pribadi; riwayat pemakaian atau analitik; pengenal iklan.

Anak-anak

Aplikasi ini ditujukan untuk pemilik usaha (dewasa). Aplikasi tidak dirancang untuk anak-anak dan tidak mengumpulkan data anak.

Keamanan

Data toko berada di penyimpanan internal aplikasi yang tidak dapat dibaca aplikasi lain pada perangkat yang tidak di-root. Kami menyarankan Anda mengaktifkan kunci layar perangkat dan membuat cadangan berkala melalui menu Pengaturan → Data → Ekspor.

Hak Anda

  • Melihat seluruh data: langsung di dalam aplikasi.
  • Mengekspor data: menu Pengaturan → Data → Ekspor (JSON).
  • Menghapus data: menu Pengaturan → Pemeliharaan data, atau hapus data aplikasi melalui pengaturan Android.

Perubahan kebijakan

Bila kebijakan ini berubah, tanggal "Terakhir diperbarui" di atas akan diubah. Perubahan besar akan diumumkan di dalam aplikasi.
